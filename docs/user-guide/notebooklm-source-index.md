## Prompts sugeridos para NotebookLM

### Prompt 1 — Visión general
```
Explicame PLIFE Growth OS como si fuera un usuario nuevo que entra por primera vez.
```

### Prompt 2 — Primer día
```
Creame una guía paso a paso para usar PLIFE Growth OS durante el primer día.
```

### Prompt 3 — Audio de capacitación
```
Generame un audio/resumen para capacitar a un asesor comercial.
```

### Prompt 4 — Preguntas frecuentes
```
Armame una lista de preguntas frecuentes y respuestas sobre el sistema.
```

### Prompt 5 — Después de crear registros
```
Explicame qué debe hacer un usuario después de crear una empresa, contacto, oportunidad o campaña.
```

### Prompt 6 — Guion de capacitación
```
Creame un guion de capacitación de 20 minutos para enseñar PLIFE Growth OS.
```

### Prompt 7 — Flujo desde cero
```
Explicame el flujo desde cero: pantalla vacía, crear empresa, contacto, oportunidad, seguimiento y campaña.
```

## Notas de uso

- Los datos demo del tutorial (`Empresa Demo Tutorial PLIFE`, `Laura Demo`, etc.) son **solo para capacitación**. No mezclar con clientes reales.
- PLIFE Growth OS **no calcula pólizas**, **no automatiza ventas** ni **reemplaza sistemas oficiales de MAPFRE**.
- Toda sugerencia de IA o Compliance requiere **revisión humana**.
